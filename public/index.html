DEVICES

设备、配对与恢复

通过已配对的 USB 连接配置 Wi‑Fi
首次安装与故障恢复
  1. 运行 npm run release:firmware 生成并校验完整镜像。
  2. 用 USB 连接 Tab5，运行 npm run flash:firmware -- --port 设备串口。
  3. 生成配对码并在设备屏幕输入；保持 USB 连接，在这里写入 Wi‑Fi 与电脑局域网 IPv4。
  4. 设备会重启并改用 Wi‑Fi；USB 始终是可靠备用和重新配网通道。
  5. 异常时先撤销旧凭据并重新配对；固件无法启动时追加 --erase 完整恢复。
